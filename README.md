# Мамин Помічник 💚

Програма для Redmi 9A (і інших Android-телефонів), щоб телефон працював швидше.

## Що вміє
- 🏠 **Головна**: оцінка стану телефону (0–100), оперативна пам'ять, пам'ять для файлів, батарея й температура, скільки днів без перезавантаження.
- 🚀 **«Прискорити зараз»**: зупиняє фонові програми й показує, скільки пам'яті звільнено.
- 🧹 **Очистка**: знаходить APK-файли, кеш, мініатюри, тимчасові файли, переглянуті статуси WhatsApp, великі відео й старі завантаження. Без підтвердження нічого не видаляє.
- 📱 **Додатки**: усі програми від найбільшої, кнопки «Інфо» (очистити кеш) і «Видалити», підказки про важкі програми (Facebook, TikTok...).
- 💡 **Поради**: 10+ простих порад для MIUI з кнопками, що відкривають потрібні налаштування.

## Як зібрати APK безкоштовно через GitHub (потрібен комп'ютер)
1. Зареєструйся на https://github.com.
2. Натисни **New repository** → назва, наприклад, `mamin-pomichnyk` → **Create repository**.
3. Натисни **uploading an existing file** і перетягни туди ВЕСЬ вміст розпакованої папки (не саму папку, а все, що всередині). Натисни **Commit changes**.
4. Перевір, що з'явилася папка `.github`. Якщо її немає: **Add file → Create new file**, у полі назви напиши `.github/workflows/build.yml`, встав вміст цього файлу з архіву → **Commit**.
5. Відкрий вкладку **Actions** → **Build APK**. Зачекай 3–5 хвилин до зеленої галочки ✅.
6. Відкрий цей запуск → внизу **Artifacts** → **MaminPomichnyk-apk**. Завантажиться zip, а в ньому файл `app-debug.apk`.

## Або через Android Studio
**Open** → обери цю папку → дочекайся завантаження → **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.

## Як встановити на телефон
1. Скинь `app-debug.apk` на телефон (Telegram, кабель, Google Диск).
2. Відкрий файл → дозволь «Встановлення з невідомих джерел».
3. MIUI може показати попередження — для програм не з Play Маркету це нормально. Натисни «Продовжити» / «Все одно встановити».
4. Відкрий «Мамин Помічник» → вкладка «Очистка» → дозволь доступ до пам'яті.
